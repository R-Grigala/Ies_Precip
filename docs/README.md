# დოკუმენტაცია

ეს დოკუმენტაცია აღწერს რეპოზიტორიაში არსებულ კოდს და მის ამჟამინდელ ქცევას. თუ კოდი და დოკუმენტი ერთმანეთს არ ემთხვევა, უპირატესობა კოდს ენიჭება.

## გზამკვლევები

- [არქიტექტურა და მონაცემთა ნაკადი](architecture.md) — აპის გაშვება, გვერდები, სერვისები და scheduler.
- [მონაცემთა მოდელი](data-model.md) — ცხრილები, კავშირები და ჩანაწერების მნიშვნელობა.
- [API ცნობარი](api.md) — REST რესურსები, ავტორიზაცია, შეყვანა და პასუხები.
- [კონფიგურაცია და ოპერირება](setup-and-operations.md) — ლოკალური გაშვება, Docker, ბაზა, მიგრაციები და ცნობილი შეზღუდვები.

## მთავარი შესასვლელი

[app.py](../app.py) ქმნის `src.create_app()`-ით Flask აპს. აპის factory, extensions, blueprint-ები და CLI ბრძანებები რეგისტრირდება [src/__init__.py](../src/__init__.py)-ში.
